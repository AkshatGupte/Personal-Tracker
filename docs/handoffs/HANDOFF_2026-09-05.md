## 2. The big change: Tasks are gone

`CLAUDE.md`, `docs/SCHEMA.md`, `docs/PRD.md` and `docs/ROADMAP.md` are all
already updated for this. Read them rather than this section for detail. In one
paragraph, so a fresh session is not blindsided:

A Track now holds a **recursive tree of Topics**, at most 5 levels deep. A Topic
with children is a parent and is not actionable; one without is a **leaf**, and a
leaf is the unit of activity. Activity is a **per-node, per-day count** with undo
— not a once-daily check-in. `Task`, `TaskCheckIn` and `CompletionLog` were
dropped outright; `TopicActivity` is the single source of truth and every figure
derives from it on read.

The database was **reset** to apply this (with explicit user consent — Prisma's
CLI refuses `migrate reset` without it) and reseeded from `prisma/seed.mjs`.

## 4. Known issues — one real, one open by choice

- **A 4px horizontal overflow on the tree view at 320px.** `TopicTree`'s
  per-node control row (`+ Inside / Rename / Move / ↑ / ↓ / Delete`) is
  `shrink-0`, and five levels of indentation leave it nothing to compress.
  `scrollWidth` is 324 against a 320 client width, on every frame — it is a
  layout fault, not a transient. Found while verifying something else and
  **deliberately not fixed**, because that request was scoped to the elevation
  graph. Letting that row wrap is the likely one-line fix.

- **The streak-milestone celebration is not rendered.** `milestoneCrossed` in

  it comes back it belongs on the first activity of a day.

- **There is no custom `app/not-found.tsx`**, so a stale URL gets Next's stock
  404 — the one screen in the app with no design on it. Offered, not taken up.

- **`sv-page-in` holds a 14px translate** while a route is slow to paint. Can
  flash a horizontal scrollbar. Pre-existing, minor, offered and not taken up.
  The one-character fix is to start the keyframe at `-14px`.

## 5. Traps that have cost real time

- **Never kill Next by process-name pattern.** Three times this session a
  `next dev` was killed as a stale orphan and `.next` cleared under it. It was
  the *user's own server on :3000*. Resolve the port first
  (`ss -lptnH 'sport = :3000'`), kill by that pid, and never `rm -rf .next`
  without knowing nothing else is serving from it.

- **If another server legitimately holds `.next`**, do not fight it. Copy the
  working tree to the scratch directory, symlink `node_modules`, and run there on
  its own port and its own database copy. Full recipe in `qa/README.md`. Note
  `rsync --delete-excluded` will destroy that symlink — do not use it.

- **QA scripts: assert the page you landed on before measuring it.** An argv
  slot slip made a script measure `/tracks/x?view=tree` — a 404 page — and report
  "no overflow across 120 frames". The clean result came from a page that does
  not exist. This slip has happened four times; being more careful is not the
  fix, asserting the URL is.

- **Prisma writes `DateTime` as ISO *text*, not integer milliseconds.** SQLite
  orders by type class before value, so integer rows silently match nothing on
  any `date >= ...` filter. `prisma/seed.mjs` asserts this now and fails loudly.

- The `.next` corruption trap and the `[n]` grep trick are unchanged — see
  `qa/README.md`.
