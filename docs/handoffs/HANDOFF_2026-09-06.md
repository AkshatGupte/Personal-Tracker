## 3. What was built in the last two sessions

All of it is written up properly — **read those rather than re-deriving any of
it.** `docs/DEV_REPORT.md` has six entries dated 2026-09-05/06, newest first, in
plain language; `docs/DECISIONS.md` has the matching reasoning with the numbers.

In short:

1. **`DimensionalSpots` is a tear generator, not a blob generator.** The outline
   is built from a jagged spine outward (two lips walked along a line of
   failure), growth lives in the geometry rather than in a transform, and cels
   are an ordered progression from sealed hairline to widest and back. Two
   archetypes were replaced because they *were* the blob reading. `/lab` renders
   it in isolation; `qa/tear-shots.mjs` freezes one at nine points of its life.
2. **Tears are ~3x less frequent.** Interval 15-30s, cap 2 (1 under 640px), and
   the chain probabilities halved — measured at one every 15.0s with something
   on screen 25% of the time, against ~6.9s and 70%+ before.
3. **The ink halo.** One 1px ring of `--bg` in eight directions, inherited from
   `body`, with five opt-outs. It is a halo and never a stroke, because a stroke
   reads as weight and the display face has one weight. This is what keeps text
   legible over the atmosphere and it is *scroll-independent*.
4. **The UX audit** — 40 fixes: tree depth indentation, control-column
   alignment, focus handling for four inline forms, scroll preservation on the
   view toggle, pointer cursors, WCAG boundary contrast, row hover, focus-ring
   colour, a 12px type floor, a `main` landmark and skip link, accessible names
   on every row action, per-cell chart alternatives, and a unified coverage
   vocabulary ("worked today" everywhere; "complete" is gone).

## 6. How to look at the UI — read this before starting a server

**The user runs their own dev server on `:3000` from the project root.** It was
broken once this session by `rm -rf .next` while it was serving, which produced
500s on every route — the exact failure `qa/README.md` warns about. It had to be
killed and restarted.

**The rule that would have prevented it: resolve the port *before* touching
anything, not after.**

```
ss -lptnH 'sport = :3000'                       # who is actually serving
ps -eo pid,args | grep -E "[n]ext-server"       # note the [n] — a plain grep matches your own shell
```

**Never run a second server from the project root, and never clear `.next`
there.** Copy the tree out instead — this is the pattern that works and it costs
about fifteen seconds:

```
S=<scratchpad>
rsync -a --exclude=.next --exclude=node_modules --exclude=.git ./ "$S/iso/"
ln -sfn "$PWD/node_modules" "$S/iso/node_modules"
cp prisma/dev.db "$S/iso/qa.db"          # never point a server at prisma/dev.db
cd "$S/iso" && DATABASE_URL="file:$PWD/qa.db" npx next dev -p 3489
```

The copy has its own `.next`, so the two can never collide.

**Seed data:** `DATABASE_URL="file:$S/iso/qa.db" node prisma/seed.mjs`. Note that
**re-seeding regenerates the track UUIDs**, so any script holding a `/tracks/<id>`
path needs the new id afterwards:

```
node -e "const D=require('better-sqlite3');const db=new D('<db>');
  for(const r of db.prepare('SELECT id,name FROM Track').all())console.log(r.name+'='+r.id)"
```

DSA is the deep track (all five levels, depth-5 leaves); Spanish is only two
deep. **Testing tree depth or the depth-5 `+ Inside` behaviour against Spanish
proves nothing** — that mistake cost a round trip this session.

## 7. The checks that exist, and what each one is for

| Script | Asserts |
|---|---|
| `qa/spots-check.mjs` | the tear effect: overflow at 5 widths, hit-testing, layer order, archetype variety, corruption is transient and restores, frame cost, reduced motion |
| `qa/contrast-check.mjs` | **glyph** contrast, halo-aware two-frame method. `NO_HALO=1` strips the halo and measures the same way |
| `qa/column-contrast.mjs` | **region** ground behind the content column at 4 scroll offsets. Currently fails by decision |
| `qa/tear-shots.mjs` | freezes one tear at nine points of its life and crops it at 2x |
| `./qa/run-tests.sh` | the lib unit tests |

`qa/README.md` documents all of them, including the traps. Two worth repeating
because they cost time this session and will again:

- **A backslash inside a `page.eval` template literal is eaten.** `/[\d.]+/g`
  becomes `/[d.]+/g`, silently. It disabled a whole predicate and the check
  confidently reported 1.03:1 on ink-on-yellow buttons.
- **A backtick inside a `page.eval` template literal ends the string**,
  including in a comment.
- `qa/cdp.mjs` now collects `console.error` as well as exceptions and `Log`
  entries. It did not before, which meant "the console is clean" was being
  reported by a check that could not see a React hydration warning at all.
